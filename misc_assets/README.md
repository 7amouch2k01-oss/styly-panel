# 📦 Styly Miscellaneous Assets & Reference Files (`misc_assets/`)

This directory houses non-production resources, development assets, UI design references, offline test suites, and historical snapshots used during the development of the **Styly** platform.

---

## 📂 Subdirectories & Resource Breakdown

| Folder / File | Purpose & Contents |
| :--- | :--- |
| **`the mobile application screen shots/`** | Visual reference captures and UI mockups demonstrating the mobile layout, explore grid, and feed behaviors. |
| **`brand dashboard/`** | Visual reference assets and UI specifications for the brand partner store management views. |
| **`parts brands/`** | Brand partner collateral, reference assets, and sample media. |
| **`filters/`** | UI reference design captures for fashion search and category filtering mechanisms. |
| **`test-auth.mjs`** | Standalone Node.js script for validating authentication flows, cookie parsing, and session lifecycle. |
| **`test-security.mjs`** | Standalone audit script for testing role escalation safeguards and unauthorized procedure rejections. |
| **`smtp_config.json`** | Historical SMTP configuration reference (superseded by Brevo REST API v3 over HTTPS). |
| **`start_guide.txt`** | Quick-start notes and initial configuration reference. |
| **`template.json`** | Base blueprint configuration templates. |

---

> [!NOTE]
> Files in this directory are meant for reference, design auditing, and offline testing. They are excluded from production bundling to keep deployment lightweight and clean.
